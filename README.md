# Pro Elite Jeans Store

## Setup Development Environment

- Install `NodeJs` and `MongoDB Compass`
- Install dependencies using `npm i`
- Run `npm run dev` to start the development server

### Optional VS Code Extensions

- ESLint
- Prettier

### Other Scripts

- `npm run start` Start application without watching for changes
- `npm run lint` Highlight lint issues using ESLint
- `npm run lint:fix` Fix lint issues using ESLint
- `npm run format` Format files using Prettier

## General Conventions

- Public methods, if documented, should use a JS DOC Comment

## Naming Conventions

- Model files end in Model.js
- Controller files end in Controller.js
- Route files end in Route.js
